# 🎓 Student Management System

A simple and modular **Student Management System** developed using Python and JSON. This project allows users to manage student information through CRUD operations and store data in a JSON file.

## 🚀 Features

- **Add Student** – Add a new student with name, surname, age and grades.
- **Show Students** – Display all registered students.
- **Update Student** – Update existing student information.
- **Delete Student** – Remove a student from the system.
- **Search Student** – Find students by their ID.
- **JSON Database** – Store and retrieve student data using a JSON file.
- **Exception Handling** – Handle errors using `try-except` blocks.
- **Modular Structure** – Organize the project into separate Python modules and functions.

## 🛠️ Technologies Used

- Python 3
- JSON
- Functions
- CRUD Operations
- Exception Handling
- Python Modules

## ⚙️ Installation & Usage

1. Clone the repository:

```bash
git clone https://github.com/huseyN259/StudentManagementSystem.git
```

2. Navigate to the project directory:

```bash
cd StudentManagementSystem
```

3. Run the application:

```bash
python main.py
```
